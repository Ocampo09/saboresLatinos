# 🍽️ Sabores Latinos - Sitio Web Oficial

Sitio web completo desarrollado para el restaurante **Sabores Latinos**, un restaurante de comida colombiana y latina ubicado en Leganés, Madrid (España).

> Proyecto real desarrollado como parte de mi formación en programación web.

---

## 🌐 Ver en vivo

👉 [saboreslatinos.github.io](https://tuusuario.github.io/saboresLatinos) 

---

## 📸 Vista previa

El sitio incluye las siguientes secciones:

- **Inicio** – Hero con imagen de fondo y presentación del restaurante
- **Quiénes Somos** – Descripción del restaurante con carrusel de fotos
- **Carta / Menú** – Galería de platos con lightbox interactivo
- **Ubicación** – Mapa de Google Maps integrado
- **Contacto** – Links a WhatsApp, Instagram y Facebook

---

## 🛠️ Tecnologías utilizadas

| Tecnología | Uso |
|---|---|
| **HTML5** | Estructura semántica del sitio |
| **CSS3** | Estilos, animaciones y diseño responsive |
| **JavaScript** | Carrusel, lightbox y menú hamburguesa |
| **Font Awesome** | Iconografía |
| **Google Maps Embed** | Mapa de ubicación del restaurante |

---

## ✨ Características

- ✅ Diseño **responsive** (adaptado a móvil, tablet y escritorio)
- ✅ Menú hamburguesa para dispositivos móviles
- ✅ **Carrusel de imágenes** del restaurante
- ✅ **Lightbox** para ver el menú ampliado
- ✅ Integración con **Google Maps**
- ✅ Links directos a **redes sociales** y **WhatsApp**
- ✅ SEO básico con meta tags (keywords y description)
- ✅ Premios **Restaurant Guru 2024 y 2025** integrados

1. Clona este repositorio:

2. Abre el archivo `index.html` en tu navegador.

No requiere instalación de dependencias ni servidor adicional.
